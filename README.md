# 🐍 Python do Zero

Uma plataforma gratuita para aprender **Python do zero**, com aulas em texto, exemplos de código para copiar e testar, e exercícios no fim de cada módulo.

## 📚 Módulos do curso

| Módulo | Tema |
|--------|------|
| 01 | Introdução ao Python (instalação, primeiro programa) |
| 02 | Variáveis e tipos de dados |
| 03 | Entrada e saída de dados (`input`, `print`, f-strings) |
| 04 | Condicionais (`if`, `elif`, `else`) |
| 05 | Laços de repetição (`for`, `while`) |
| 06 | Listas e dicionários |
| 07 | Funções (`def`, parâmetros, `return`) |

## 🚀 Como usar

É um site estático: basta abrir o arquivo `index.html` no navegador, ou publicar de graça no [GitHub Pages](https://pages.github.com/):

1. Vá em **Settings → Pages** neste repositório.
2. Em **Source**, escolha **Deploy from a branch** e selecione `main` na pasta `/ (root)`.
3. Pronto — o site ficará no ar em `https://<seu-usuario>.github.io/ideia-boa/`.
