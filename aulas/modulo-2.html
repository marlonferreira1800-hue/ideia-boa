Módulo 02

Variáveis e tipos de dados

Nesta aula você vai aprender a guardar informações na memória do computador usando variáveis.

O que é uma variável?

Uma variável é como uma caixinha com um nome onde guardamos um valor. Em Python, criamos uma variável atribuindo um valor a um nome:

nome = "Ana"
idade = 25
altura = 1.65

Depois podemos usar essas variáveis no programa:

print(nome)
print(idade)

Principais tipos de dados

  • str — texto (sempre entre aspas): "Olá" ou 'Olá'
  • int — números inteiros: 10, -3
  • float — números com casas decimais: 3.14, 0.5
  • bool — verdadeiro ou falso: True ou False

Descobrindo o tipo de uma variável

mensagem = "Oi"
print(type(mensagem))   # <class 'str'>

numero = 42
print(type(numero))     # <class 'int'>

Operações com números

a = 10
b = 3

print(a + b)   # 13  soma
print(a - b)   # 7   subtração
print(a * b)   # 30  multiplicação
print(a / b)   # 3.3333... divisão
print(a // b)  # 3   divisão inteira (sem casas decimais)
print(a % b)   # 1   resto da divisão
print(a ** b)  # 1000 potência (10 elevado a 3)

Juntando textos

Com textos, o + serve para juntar (concatenar):

primeiro = "Ana"
ultimo = "Silva"
nome_completo = primeiro + " " + ultimo
print(nome_completo)  # Ana Silva

Convertendo tipos

numero_texto = "25"
numero = int(numero_texto)      # vira número inteiro
print(numero + 5)               # 30

texto = str(100)                # vira texto
print(texto + " reais")         # 100 reais

Regras para nomear variáveis

  • Pode usar letras, números e underline (_), mas não pode começar com número.
  • Não use espaços — prefira nome_completo no lugar de nome completo.
  • Evite acentos e caracteres especiais nos nomes.
