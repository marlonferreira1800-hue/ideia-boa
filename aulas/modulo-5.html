Módulo 05

Laços de repetição (for e while)

Imagine ter que escrever print() 100 vezes. Com laços de repetição, o computador repete o código para você.

for — repetir uma quantidade conhecida de vezes

A função range() gera uma sequência de números:

for i in range(5):
    print(i)
# 0 1 2 3 4

O range(5) gera os números de 0 até 4. También dá para começar em outro número:

for i in range(1, 6):
    print(i)
# 1 2 3 4 5

Tabuada com for

numero = int(input("Tabuada de qual número? "))

for i in range(1, 11):
    resultado = numero * i
    print(f"{numero} x {i} = {resultado}")

Somando uma lista de números

total = 0
for i in range(1, 101):
    total = total + i
print("A soma de 1 a 100 é", total)  # 5050

while — repetir enquanto uma condição for verdadeira

contador = 1
while contador <= 5:
    print(contador)
    contador = contador + 1
# 1 2 3 4 5

Cuidado: se a condição nunca ficar falsa, o programa fica preso num loop infinito. Sempre garanta que a variável da condição muda dentro do laço.

while com input — validar até acertar

senha = ""
while senha != "1234":
    senha = input("Digite a senha: ")
print("Acesso permitido!")

break e continue

# break: sai do laço na hora
for i in range(10):
    if i == 5:
        break
    print(i)   # imprime 0 1 2 3 4

# continue: pula para a próxima repetição
for i in range(6):
    if i == 3:
        continue
    print(i)   # imprime 0 1 2 4 5 (pula o 3)
