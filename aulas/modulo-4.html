Módulo 04

Condicionais (if, elif, else)

Programas precisam tomar decisões. Nesta aula você vai aprender a fazer o código escolher caminhos diferentes.

Operadores de comparação

  • == igual a
  • != diferente de
  • > maior que   < menor que
  • >= maior ou igual   <= menor ou igual

Essas comparações devolvem True (verdadeiro) ou False (falso).

if — se isso, faça aquilo

idade = int(input("Qual é a sua idade? "))

if idade >= 18:
    print("Você é maior de idade.")

print("Fim do programa.")

Importante: em Python, o bloco dentro do if é definido pela indentação (os espaços no início da linha). Use 4 espaços.

else — caso contrário

idade = int(input("Qual é a sua idade? "))

if idade >= 18:
    print("Maior de idade.")
else:
    print("Menor de idade.")

elif — várias condições

nota = float(input("Digite a nota (0 a 10): "))

if nota >= 7:
    print("Aprovado!")
elif nota >= 5:
    print("Recuperação.")
else:
    print("Reprovado.")

Condições combinadas com and / or / not

idade = int(input("Idade: "))
tem_cnh = input("Tem CNH? (s/n): ")

if idade >= 18 and tem_cnh == "s":
    print("Pode dirigir.")
else:
    print("Não pode dirigir.")

# or — basta uma ser verdadeira
if tem_cnh == "s" or idade >= 21:
    print("Condição atendida.")

# not — inverte o valor
if not tem_cnh == "s":
    print("Não tem CNH.")

Comparando textos

senha = input("Digite a senha: ")

if senha == "python123":
    print("Acesso permitido.")
else:
    print("Senha incorreta.")
