Módulo 07

Funções

Se você vai repetir o mesmo código várias vezes, crie uma função: um bloco de código com nome que pode ser reutilizado.

Criando sua primeira função

Use def seguido do nome da função e dos parênteses. O código da função fica indentado:

def saudacao():
    print("Olá! Seja bem-vindo ao curso.")

saudacao()   # chama a função
saudacao()   # chama de novo
# Olá! Seja bem-vindo ao curso.
# Olá! Seja bem-vindo ao curso.

Funções com parâmetros

Parâmetros são valores que a função recebe para trabalhar:

def saudacao(nome):
    print(f"Olá, {nome}!")

saudacao("Ana")      # Olá, Ana!
saudacao("Carlos")   # Olá, Carlos!

Funções que devolvem um valor: return

O return devolve um resultado que pode ser guardado em uma variável:

def dobro(numero):
    return numero * 2

resultado = dobro(7)
print(resultado)   # 14
print(dobro(10))   # 20

Função com vários parâmetros

def area_retangulo(largura, altura):
    return largura * altura

print(area_retangulo(5, 3))   # 15
print(area_retangulo(10, 2))  # 20

Parâmetros com valor padrão

Se o valor não for informado, a função usa o padrão definido:

def apresentar(nome, curso="Python do Zero"):
    print(f"{nome} está estudando {curso}.")

apresentar("Ana")                    # Ana está estudando Python do Zero.
apresentar("Carlos", "JavaScript")   # Carlos está estudando JavaScript.

Por que usar funções?

  • Reutiliza código — escreve uma vez, usa várias vezes.
  • Organiza o programa — cada função faz uma tarefa.
  • Facilita manutenção — se mudar, muda em um só lugar.

Exemplo completo: calculadora simples

def somar(a, b):
    return a + b

def subtrair(a, b):
    return a - b

def multiplicar(a, b):
    return a * b

def dividir(a, b):
    if b == 0:
        return "Erro: não dá para dividir por zero."
    return a / b

a = float(input("Primeiro número: "))
b = float(input("Segundo número: "))

print("Soma:", somar(a, b))
print("Subtração:", subtrair(a, b))
print("Multiplicação:", multiplicar(a, b))
print("Divisão:", dividir(a, b))
