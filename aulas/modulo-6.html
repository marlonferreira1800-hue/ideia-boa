Listas e dicionários

Até agora guardamos um valor por variável. Nesta aula você vai aprender a guardar vários valores de uma vez.

Listas

Uma lista é uma coleção ordenada de valores, escrita entre colchetes:

frutas = ["maçã", "banana", "laranja"]
print(frutas)          # ['maçã', 'banana', 'laranja']
print(frutas[0])       # maçã (o primeiro elemento é o índice 0)
print(frutas[2])       # laranja
print(len(frutas))     # 3 (quantidade de itens)

Alterando e adicionando itens

frutas[1] = "uva"              # troca a banana por uva
frutas.append("melancia")      # adiciona no fim
frutas.remove("uva")           # remove um item pelo valor
print(frutas)

Percorrendo uma lista com for

notas = [8.5, 7.0, 9.2, 6.5]

soma = 0
for nota in notas:
    soma = soma + nota

media = soma / len(notas)
print(f"Média: {media:.2f}")

Dicionários

Um dicionário guarda pares de chave e valor, entre chaves. É como uma ficha cadastral:

pessoa = {
    "nome": "Ana",
    "idade": 25,
    "cidade": "São Paulo"
}

print(pessoa["nome"])     # Ana
pessoa["email"] = "ana@email.com"   # adiciona um novo campo
print(pessoa)

Percorrendo um dicionário

for chave, valor in pessoa.items():
    print(f"{chave}: {valor}")

Lista de dicionários — uma agenda simples

agenda = [
    {"nome": "Ana", "telefone": "1111-1111"},
    {"nome": "Carlos", "telefone": "2222-2222"}
]

for contato in agenda:
    print(f"{contato['nome']} — {contato['telefone']}")
