Módulo 01

Introdução ao Python

Nesta primeira aula você vai entender o que é Python, para que ele serve e vai escrever o seu primeiro programa.

O que é Python?

Python é uma linguagem de programação criada para ser simples de ler e de escrever. Por isso ela é uma das melhores escolhas para quem está começando a programar. Com Python dá para criar sites, aplicativos, jogos, automações e até trabalhar com inteligência artificial.

Instalando o Python

  1. Acesse o site oficial python.org e baixe a versão mais recente do Python.
  2. Durante a instalação no Windows, marque a opção Add Python to PATH.
  3. Para confirmar que deu certo, abra o terminal e digite: python --version

Seu primeiro programa: olá, mundo!

Abrindo o terminal, digite python e aperte Enter. Depois escreva o código abaixo e aperte Enter:

print("Olá, mundo!")

O comando print() mostra um texto na tela. Esse é o comando que você vai usar o tempo todo para ver o resultado dos seus programas.

Salvando código em um arquivo

Também dá para escrever o programa em um arquivo de texto e executar depois. Crie um arquivo chamado ola.py com o conteúdo:

print("Olá, mundo!")
print("Meu primeiro programa em Python")

E execute no terminal com:

python ola.py

Comentários no código

Tudo que vem depois do # é ignorado pelo Python. Use isso para deixar anotações no seu código:

# Esse é o meu primeiro programa
print("Olá, mundo!")  # mostra o texto na tela

Crie um arquivo chamado apresentacao.py que imprime na tela o seu nome, sua idade e a cidade onde você mora, cada um em uma linha.
