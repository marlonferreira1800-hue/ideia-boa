Módulo 03

Entrada e saída de dados

Até agora os programas só mostraram coisas na tela. Nesta aula você vai aprender a ler o que o usuário digita.

Saída de dados: print()

Já vimos o print(). Ele também permite mostrar várias coisas de uma vez, separadas por vírgula:

nome = "Carlos"
idade = 30
print("Nome:", nome, "| Idade:", idade)
# Nome: Carlos | Idade: 30

Entrada de dados: input()

O comando input() pausa o programa e espera o usuário digitar algo e apertar Enter. O que foi digitado vira um texto (str):

nome = input("Qual é o seu nome? ")
print("Prazer em te conhecer,", nome, "!")

Lendo números com input()

Como o input() devolve sempre texto, precisamos converter para número quando quisermos fazer contas:

idade_texto = input("Qual é a sua idade? ")
idade = int(idade_texto)
print("Daqui a 10 anos você terá", idade + 10, "anos.")

# Para números com vírgula/ponto decimal, use float:
altura = float(input("Qual é a sua altura? "))
print("Sua altura é", altura)

Textos formatados com f-string

A f-string (a letra f antes das aspas) permite colocar variáveis dentro do texto de forma fácil:

nome = input("Seu nome: ")
idade = int(input("Sua idade: "))
print(f"Olá, {nome}! Você tem {idade} anos.")
# Olá, Ana! Você tem 25 anos.

Exemplo completo: calculadora de IMC

peso = float(input("Digite seu peso (kg): "))
altura = float(input("Digite sua altura (m): "))
imc = peso / (altura ** 2)
print(f"Seu IMC é {imc:.2f}")

O :.2f dentro da f-string mostra o número com 2 casas decimais.
